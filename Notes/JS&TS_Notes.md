## Variables in Javascript (basics1.js)
- Variables in JS is loosely typed, means it can store any variable in var
- JS version till ES5 uses only var and from JS version ES6 new variables were introduced let and const
- Difference between var, let and const:(we can use var first and then let for the same variable)
    - We cannot redeclare variable with let keyword, but possible with var
    - With let reassigning is allowed, but not redeclaring. But with var both are possible
    - const and let is, it is constant, we cannot reassign it too
- Data Types in JS:
    - Number
    - String
    - Boolean
    - Null
    - Undefined - no value assigned to a variable
- To find the datatype of variable, use the keyword typeof(Variable_Name)
- Operators in JS:
    - +, -, *, /, =, ! - only applicable on boolean

## Condition (basics2.js)
- if condition: check if it's true and execute the block, else execute the else block. Also, to further use multiple conditions we can use else if
- While loop: if condition is true, the loop keep executing until the condition is false
- Use while to execute the expression for the condition
- do while loop: one round of execution happens before the execution
- for loop has all initialize, comparison and increment/decrement operator
- Use for loop, when you know the number of time you want to run the loop
